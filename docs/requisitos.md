# Requisitos implementados

## Requisitos funcionais

RF01 - Menu principal.

RF02 - Tabuleiro de 10x10 para cada jogador.

RF03 - Navio pequeno de 2 posições e navio grande de 4 posições.

RF04 - Posicionamento automático sem sobreposição.

RF05 - Validação de coordenadas e rejeição de jogadas repetidas.

RF06 - Mensagens de água, acerto e navio afundado.

RF07 - Exibição do vencedor, quantidade de jogadas e tempo.

RF08 - Nova partida pelo menu.

RF09 - Jogador x Computador e Jogador x Jogador.

RF10 - Conferência dos navios antes da partida.

RF11 - Histórico das jogadas.

RF12 - Estatísticas de partidas, acertos, jogadas e aproveitamento.

RF13 - Replay da última partida.

## Requisitos não funcionais

RNF01 - Projeto individual.

RNF02 - Python 3.10 ou superior.

RNF03 - Código organizado seguindo PEP8.

RNF04 - Sistema dividido em módulos coesos.

RNF05 - Tratamento de entradas inválidas.

RNF06 - Código sem dependência de recursos exclusivos do Windows para o funcionamento principal.

RNF07 - Interface textual.

RNF08 - Interface gráfica não utilizada nesta versão.

## Regras de negócio

RN01 - Coordenadas entre A1 e J10.

RN02 - Jogadas repetidas são rejeitadas.

RN03 - Navio afundado após todas as posições serem atingidas.

RN04 - A partida termina quando todos os navios adversários forem afundados.

RN05 - O computador escolhe automaticamente posições ainda não utilizadas.
